# AIE1903 课程项目指南

**AI 探索 III —— 面向自动驾驶的 AI：动手实践入门**

**2026–2027 秋季学期**

**什么（What）**？ – 项目内容与交付物

自行选择一个与**面向自动驾驶的 AI** 相关的主题（请参阅第1周分发的项目主题列表以获取建议方向，包括但不限于：基于摄像头的感知、BEV/3D 可视化、高清地图探索、轨迹预测、路径规划、避障、闭环仿真、使用视觉语言模型进行驾驶场景推理、安全/故障案例分析，或系统设计比较），并协作开发该项目。

强烈建议您使用真实的自动驾驶数据——使用小型、可访问的子集，而不是完整的大规模数据集，以便一切都能在普通计算机上运行。为您提供 GPU，但不是必须的。

不同的团队可以选择不同或相似的方向；团队之间没有直接的竞争。

请在下面指定的截止日期前提交以下材料：

1. **期中提案展示**：一次简短的课堂展示（每组约 **10 分钟**，外加 **5 分钟**的问答和教师反馈），展示下方的提案。每个团队必须说明其预期的最终输出及其主要的数据/工具/进度风险。收到的反馈应整合到最终提交的提案文档中。
2. **项目提案**：一份文档（4-6页，约每人一页），包括以下部分以回答相应的问题：
   1. **引言**：您选择了什么主题，为什么？它与自动驾驶流水线的哪个（些）部分相关？
   2. **相关工作**：您的想法来自哪里，您将从哪里获取额外资源（参考文献、库、数据集、预训练模型等）？
   3. **我们的工作**：您将详细实现什么，例如项目中的整体架构和各个组件，以及使您的项目与众不同的亮点是什么？定义一个**最小可行版本**、一个可选的**扩展**，以及如果工具或数据比预期更困难时的**后备计划**。
   4. **证据与评估**：您的最终演示或分析将展示什么？完成句子：“我们的最终证据将是……”，并说明该证据将证明什么以及不会证明什么。
   5. **进度表**：项目的里程碑（至少每两周一次）及其各自的完成日期是什么？
3. **期末展示与演示**：第13周的课堂展示。每组约有 **10 分钟**用于展示/演示，**10 分钟**用于问答、反馈和讨论。
4. **项目代码包**（主要的里程碑交付物）：项目输出，例如源代码，如果可能的话，还包括可运行的演示。包含一个简短的 README 和一个环境文件，以便该包可以被复现。
   * 项目预期能在普通笔记本电脑上以 Python 实时运行。如果您的项目无法作为独立包交付，请添加已保存的输出或录制的演示视频，并在课堂期末展示期间进行解释。
5. **项目报告**：提案的*实质性扩展*（约8-12页，约每人两页，格式类似于常规会议论文），包括以下部分以回答相应的问题：
   1. **引言**：您做了什么，为什么？特别是，与提案相比是否有任何变化，如果有，为什么？
   2. **相关工作**：您的想法来自哪里，您从哪里获得了额外资源？您从这些资源中借鉴了什么？再次说明，记录与提案相比的任何变化并解释原因。
   3. **我们的工作**：您完成了什么以及如何实现的？在借鉴的资源之外，您具体做了什么？用明确的**主张、证据和局限性**来展示您的结果：证据证明了什么，它在哪些操作条件下适用？
   4. **反思**：您遇到了什么困难以及如何克服的？通过这个项目您学到了什么，请区分课堂学习和自主学习？您项目的局限性和安全考虑是什么？
   5. **AI 工具使用声明**：您使用了哪些 AI 工具，用于什么目的，以及您如何验证其输出的正确性？

**如何（How）**？ – 评分标准

1. **期中提案展示**：15%
2. **期中提案文档**：15%
3. **期末展示与演示**：15%
4. **期末报告**：15%
5. **里程碑交付物**（项目代码包和演示材料）：40%
6. **评估方案**：对于上述任何提交，评估将如下进行：
   1. **01% ~ 20%**：提交了部分材料；
   2. **21% ~ 40%**：可读的文档（包含缺失信息）和可运行的代码/演示；
   3. **41% ~ 60%**：信息丰富的文档（包含基本信息）和正常工作的代码/演示；
   4. **61% ~ 80%**：完整的文档（包含详细信息）以及与提案匹配的功能性结果；
   5. **81% ~ 100%**：除了满足上述标准外，还有具有洞察力的文档以及有创意、有趣的项目。
7. 除上述阶梯标准外，评估还考虑清晰度、技术投入、正确性、创造力、展示质量、团队合作以及对局限性的理解。与证据相匹配的诚实主张比宽泛但无支持的主张更受重视。

**学术诚信与 AI 工具使用**

* 在整个项目过程中，允许并鼓励使用 AI 工具——用于学习、头脑风暴、编码、调试、可视化、文献探索和写作协助。学生仍需对自己工作的正确性、原创性、解释和质量负责。
* 项目报告必须包含**AI 工具使用声明**（见*什么*，第5.6项），并且每位学生必须能够解释如何使用 AI 工具以及自己的智力贡献。
* 滥用 AI 工具——例如将未经核实的 AI 生成作品作为自己的作品提交、伪造结果或使用 AI 作弊——属于学术不端行为。
* 在学期中任何时间，学生可能会被要求向助教或教师解释他们的工作。例如，这可能包括解释他们项目中随机抽取的一段代码。未能充分解释自己的代码（这可能表明存在抄袭）可能导致立即获得“F”的成绩。
