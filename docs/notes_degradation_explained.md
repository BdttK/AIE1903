# 退化档位补充说明（非 README 正文）

> 以下内容由外部粘贴进入 README，已移到此处保留；行号可能随重构变化，以 `eval/core.py` 为准。

距离阶段（range） 就是距离截断的几个档位：range40/30/20/10，只保留到自车径向距离 ≤ 40/30/20/10 m 的点，其余点全部丢掉（core.py:158-159）。它模拟传感器最大量程缩小，或雨雾、污染让远场回波失效的情况。它是确定性操作，不消耗随机种子，所以只跑 seed 0。

丢点（drop） 是随机删点：每点以概率 p 被丢弃，档位为 drop25/50/75（core.py:160-161）。它模拟低反射率（黑色车漆、行人衣物）、多线束失效、极端角度漏扫。因为它带随机性，所以用 seeds 0–2 重复 3 次，再对指标取平均。

噪声（noise） 是径向抖动：保持方位角 θ 不变，只把距离改成 r' = max(r + N(0, σ), 0)，σ = 0.05/0.10/0.20 m（core.py:162-170）。它模拟测距误差（雨雪、温度漂移、镜头脏）。注意它只扰动径向量，不改变角度，所以栅格上表现为沿射线方向的点沿射线“糊开”，不会横向散开。它同样需要多种子重复。

昼夜条件（day/night） 不是退化，而是场景属性，写死在 experiments.py:22-33 的 SCENE_META 里，并与 nuScenes 场景描述一致（1077/1094 的描述以 “Night” 开头）。它作为汇总的一个分组维度：summary_by_degradation 按 time × degradation 聚合（experiments.py:170-181），fig_day_night.png 画两条包络召回曲线（visualize.py:62-75）。

有一点需要留意：默认 4 个场景里 day 是 One North/Seaport（0061、0103），night 全在 Holland Village（1077、1094），所以“昼夜差异”其实和地点混在一起，报告里最好写成“夜间场景表现更差”，不要直接归因于光照。
